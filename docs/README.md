# MiniOneRec 源码学习指南

这套文档面向推荐系统初学者，以当前本地仓库的实际代码为依据，按“数据如何变成样本、模型如何学习、如何生成推荐”的顺序讲解。

核对版本：`5f4f733cfda387f7f6f8f158db0d300eed9471c6`。阅读范围包括仓库全部 42 个 Python 文件、Shell 脚本、配置和测试；同源的 GPR 文件通过基础文件与完整差异对照阅读。数据文件检查了结构、样本数量和 CSV／SID／info 映射，未运行大模型训练或下载权重。文中的数值实验结果只指这些本地数据检查，不表示训练复现结果。

全文遵循三个约定：

- **代码事实**：能在标出的文件、类或函数里直接找到。
- **教学解释**：解释这段计算的数学含义；公式中的示例维度不冒充已下载模型的配置。
- **实现边界**：区分已定义、已接入默认入口、依赖外部库，以及当前没有实现的功能。README 或论文中的描述不代替代码证据。
