# 11 主线精简记录

[返回文档目录](README.md)

为了集中学习 MiniOneRec，本次移除了传统推荐基线及其专用奖励入口。这是学习范围的取舍，不表示这些算法本身没有用途或被原作者弃用。

## 删除的内容

- `minionerec/models/sasrec.py`：SASRec、GRU、Caser 和独立基线训练、评测代码。
- `minionerec/models/sasrec_modules.py`：基线专用注意力与前馈模块。
- `minionerec/models/utils.py`：基线辅助函数及未接入主线的遗留模块。
- `minionerec/models/__init__.py`：原基线包声明。
- 主线与 GPR 的 RL 入口：SASRec 导入、checkpoint 加载、`cf_path` 参数、`cf_reward` 和 `sasrec` 奖励选项。
- 主 RL 训练器中已注释的 SASRec 字典残留。

历史代码仍可从 Git 查询；`docs/README_EN.md` 保留为原英文 README 备份。

## 当前 RL 奖励

两个 RL 入口保留 `rule`、`ranking`、`ranking_only`、`semantic`，启动时验证选项。默认启动脚本继续使用 `ranking`，奖励计算和 GRPO 风格损失未改动。

旧命令中的 `--cf_path` 和 `--reward_type sasrec` 不再支持。GPR 原先只在 SASRec 分支组合 `hepo_reward`，该分支现已删除；函数仍作为实验实现保留，没有新增可运行的 HEPO 入口。

## 学习主线

商品与交互数据清洗 → Qwen 提取商品向量 → RQVAE 训练与 SID 导出 → 推荐样本转换 → SFT → RL → 推理与评估。

`rq/vae/models/` 是 RQVAE 的核心模型目录，与删除的 `minionerec/models/` 无关。GPR、TS 实验、其他 SID 构建方法和数据文件仍保留；学习主线时可以暂时跳过实验目录。
